# ⚽ GesCoach

**GesCoach** es una aplicación web para la gestión integral de equipos de fútbol, diseñada para facilitar el trabajo diario de entrenadores y cuerpos técnicos.

La apliacación permite centralizar en un unico lugar la información del equipo, jugadores, entrenamientos, partidos y planificación deportiva

## 🚀 Características

* ### 👥 Gestión de jugadores
  * Datos individuales de cada jugador.
  * Información personal y deportiva
* ### 🏃‍♂️ Gestión de entrenamientos
  * Planificación de sesiones.
* ### ⚽ Gestión de partidos.
  * Registro de partidos.
  * Convocatorias.
  * Alineaciones.
  * Resultados y estadísticas.
* ### 📊 Seguimiento del equipo.
  * Control de asistencia.
  * Registro de información relevante durante la temporada.
* ### 📋 Planificación deportiva.
  * Organización de objetivos.
  * Planificación de contenidos tácticos, técnicos y físicos.
  * Seguimiento de los objetivos durante la temporada.

## 🎯 Objetivo

El objetivo de GesCoach es proporcionar a los entrenadores una herramienta sencilla y centralizada para organizar, planificar y hacer seguimiento de la actividad de un equipo de fútbol.

La aplicación busca reducir la dependencia de documentos, hojas de cálculo y diferentes herramientas independientes, concentrando la información del equipo en una única plataforma.

## 🛠️ Tecnologías

* **Frontend**: ReactJS
* **Backend**: Node.js
* **API REST**: Express.js
* **BBDD**: MongoDB
